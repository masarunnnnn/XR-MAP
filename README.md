# XR MAP

地図・3D・AR・AIを組み合わせたXR街歩きアプリ。

## Overview

XR Walkは、現在地や周辺のスポット情報を
3D・ARを使って表示する街歩きアプリです。

将来的にはAIを利用した観光案内機能も追加します。

## Technologies

- React
- TypeScript
- Three.js
- React Three Fiber
- Node.js
- WebXR
- AI API

## Features

- [ ] 地図表示
- [ ] 現在地表示
- [ ] スポット表示
- [ ] スポット詳細
- [ ] 3Dマップ
- [ ] 3Dモデル表示
- [ ] AR表示
- [ ] AI観光ガイド
